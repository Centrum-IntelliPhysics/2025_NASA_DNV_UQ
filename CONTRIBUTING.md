# Contributing to 2025_NASA_DNV_UQ

Thank you for your interest in contributing! This document provides guidelines for contributing to this repository to ensure it remains well-structured and reproducible.

## How to Contribute

### 1. Fork the Repository
Create a fork of this repository to your own GitHub account by clicking the "Fork" button at the top right of the repository page.

### 2. Branching Strategy
Create a new branch for your feature or bug fix:
```bash
git checkout -b feature/your-feature-name
```
For bug fixes, use a descriptive name like `bugfix/issue-description`. We recommend keeping your branches focused on a single issue or feature.

### 3. Make Changes
- Ensure your code is clean, well-documented, and follows the existing style.
- If you're adding a new method or script, please include appropriate comments or usage examples.

### 4. Pull Request Instructions
- Push your changes to your fork.
- Open a Pull Request (PR) against the `main` branch of the original repository.
- Provide a clear and descriptive title for your PR.
- Detail the changes you've made in the description, including context, what the PR accomplishes, and why the change is necessary.

## Code Style
Please follow PEP 8 standards for Python code. Add comments and docstrings where appropriate to explain complex logic, especially for the Physics-Informed or optimization routines.
